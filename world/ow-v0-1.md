# Overworld v0-1

*flosha, August 11, 2026*

OW (Overworld) v0-1 refers to our design documentation and development process from Phoenix World v0.0 to Phoenix World v0.1.

The OW v0-1 development is related with the Gothic Worlds v0.9 to v1.6. whereas, 1.06 equals Phoenix World v0.0, while Phoenix World v0.1 is our attempt and result of restoring the Alpha World of v0.9, while *preserving* the *relevant* additions from up to v1.06. Our World v0.1 is the harmonisation of the Alpha and the Release World, with the Alpha World taking priority. No location of the Alpha world is removed but those locations of the Release version are added that do *not conflict* with the Alpha world. In short:
* Gothic World v1.6 = Phoenix World v0.0
* Gothic World v0.9 ≠ Phoenix World v0.1
* Phoenix World v0.1 = Gothic v0.9 - 1.6


World 1.6  is what we start with, the base game before any modifications. (our first demo).





The purpose of this document is to describe in which way the world will be changed to proceed from the base world v0 to Phoenix world v1.
